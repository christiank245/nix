# dotfiles

## installation

<!-- TODO: switch to determinate nix https://docs.determinate.systems/ -->

1. install nix
   `sh <(curl --proto '=https' --tlsv1.2 -L https://nixos.org/nix/install)`

2. install nix-darwin as described in the [nix-darwin documentation](https://github.com/nix-darwin/nix-darwin?tab=readme-ov-file)

3. clone this repo
   `git clone https://github.com/christiank245/nix.git`

4. install software
   `make switch`
